# wyf 的博客

静态博客，直接使用 GitHub Pages，无需 Node.js 构建。首页、归档、分类搜索、文章阅读、Markdown 编辑、LaTeX 公式、浏览器草稿、JSON 导入导出。

## 首次更新网站

将本项目的 `index.html`、`style.css`、`app.js`、`posts.json`、`assets/`、`vendor/`、`.nojekyll` 上传到 GitHub 仓库根目录并提交。保留目录结构。GitHub 仓库 Settings → Pages 中，选择 Deploy from a branch，选择默认分支和根目录 `/ (root)`。部署完成后访问 https://j23wuyifan.github.io/ 。不需要切换到其他托管平台。

## 写文章

1. 打开网站，点击右上角「写博客」。
2. 新建文章，填写标题、日期、分类、摘要和 Markdown 正文，右侧实时预览。支持代码块、表格、`$...$` 行内公式和 `$$...$$` 块公式。
3. 修改即时保存到当前浏览器 localStorage。草稿不会公开、不会同步到别的设备，不是服务器后台；访问此页的其他人也只能编辑自己浏览器中的副本。
4. 勾选需要公开的文章「选入发布文件」，点击「导出发布文件」，得到 `posts.json`。导出文件包括所有选入的文章，而不只是当前文章。取消选入可从下次发布中移除文章。
5. 在 GitHub 仓库根目录 Add file → Upload files，上传 `posts.json` 覆盖同名文件，点击 Commit changes。等待 Pages 部署完成后，刷新查看更新。
6. 修改公开文章：在写作页选择文章并修改，重新导出并提交。删除公开文章：删除本地对应文章后重新导出提交。

**多设备：** 在另一台设备先导入最新 `posts.json` 再编辑，避免用旧本地副本覆盖新文章。完整备份可在写作页下方展开帮助，点击「备份全部草稿」；该备份包含未发布草稿，不应上传到公开仓库。导入操作会先提示确认，然后替换本地列表。定期导出备份，清理浏览器数据会丢失本地草稿。编辑器的本地副本不会自动与仓库合并。

## 本地预览

在项目目录执行 `python3 -m http.server 8000`，然后打开 http://localhost:8000 。不要双击 HTML，浏览器对本地文件的限制会导致文章 JSON 无法加载。

## 文件

- `index.html`：网站基本信息、导航、首页。
- `style.css`：配色、布局、响应式样式。
- `app.js`：文章阅读、搜索、Markdown 渲染与本地写作。
- `posts.json`：所有公开文章，UTF-8 JSON 数组。
- `assets/hero.png`：通过内置 imagegen 生成的原创动漫风夜空背景。
- `vendor/`：固定版本的 Marked 15.0.12、DOMPurify 3.2.6、KaTeX 0.16.22，含其许可证。字体也本地托管，无 CDN 依赖。

背景生成简述：原创日式动漫背景，蓝紫色黄昏湖畔铁路、星空、远山、右侧背影少女，左侧留白，无文字或水印。

已有的「你好，世界！」内容保留；题解和算法笔记明确标为示例，不代表个人做题记录。
