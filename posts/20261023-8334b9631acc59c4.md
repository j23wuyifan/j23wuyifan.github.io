## 思路
注意到一个字符串是动听的充要条件是对于所有的 $s_i = s_j$，$j - i \ge m + 3$。我们可以对每个 $x \in U$ 分别计算答案。考虑 DP，设计状态 $f_i$ 表示 $i + 1$ 可以填 $x$ 的方案数。转移考虑是不是 $i+1$ 才刚刚能填 $x$，若之前就能填 $x$，有转移 $f_i \gets (k - m - 3) \times f_{i-1}$，因为第 $i$ 位不能填 $x$ 和前面的 $s_{i-m-2} \sim s_{i - 1}$ 的 $m+2$ 个数。否则就是 $s_{i-m-2}$ 填了 $x$，有转移 $f_i \gets f_{i-m-3} \times (k-m-2)^{m + 2}$。因为 $s_{i-m-1} \sim s_{i-1}$ 只要不和前面的 $m+2$ 个数相同即可。若 $T$ 中未出现 $x$，答案就是 $f_{n-m-3}$。否则计 $x$ 出现的位置为 $p$，那么至少要 $s_{p+m+3}$ 才能填 $x$，前面的 $m+2$ 个数有 $(k-m-2)$ 种选法，总方案数就是 $f_{n-m-p-3} \times (k-m-2)^{m+2}$。

## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 1e7 + 10, mod = 998244353;
int c, q, k, m, pw[10010], f[N], n;
inline int F(int x) {
	return x < 0 ? 0 : f[x];
}
signed main() {
	cin >> c >> q >> k >> m;
	m += 2;
	pw[0] = 1;
	for (int i = 1; i <= m; i ++) pw[i] = pw[i - 1] * (k - m) % mod; 
	n = 1e7;
	f[0] = 1;
	for (int i = 1; i <= n; i ++) 
		f[i] = (f[i - 1] * (k - m - 1) % mod + F(i - m - 1) * pw[m]) % mod;
	while (q --) {
		cin >> n;
		unordered_map<int, int> mp; 
		for (int i = 1, x; i <= m; i ++) {
			cin >> x;
			mp[x] = i;
		}
		int ans = 0, t = 0, x;
		cin >> t;
		while (t --) {
			cin >> x;
			if (!mp[x]) ans = (ans + F(n - m - 1)) % mod;
			else ans = (ans + pw[mp[x]] * F(n - m - 1 - mp[x])) % mod;
		} 
		cout << ans << '\n';
	}
	return 0;
}
```
