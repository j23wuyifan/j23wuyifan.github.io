## 题意
将互不相同的 $N$ 个整数 $A_1, A_2, \cdots, A_N$ 按照一定顺序排列。

假设排列为 $f_1, f_2, \cdots, f_N$，要求：$| f_1 - f_2| + | f_2 - f_3| + \cdots + | f_{N-1} - f_N| \leq L$。

求满足题意的排列的方案数对 $10^9+7$ 取模后的结果。
$$
N \le 100,L \le 1000
$$
## 思路
考虑从大到小插入数 $x$，每次新增加的绝对值就是 $> x$ 的数构成的连续段的数量 $\times 2$。连续段 DP，维护当前的段数，绝对值的和，再维护一下首尾有没有填了。转移有 $3$ 种。
- 新开一段
- 合并两段
- 加在连续段的两侧，但不合并

复杂度 $O(n^2L)$。
## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 105, M = 1010, mod = 1e9 + 7;
int a[N], n, L, dp[N][M][3], cnt[N], f[N][M][3];
inline void add(int &x, int y) {
	x = x + y >= mod ? x + y - mod : x + y;
} 
signed main() {
	cin >> n >> L;
	if (n == 1) {
		cout << 1;
		return 0;
	}
	for (int i = 1; i <= n; i ++) cin >> a[i];
	sort (a + 1, a + n + 1);
	dp[0][0][0] = 1;
	for (int i = 0; i < n; i ++) {
		for (int j = 0; j <= i; j ++) {
			for (int k = 0; k <= L; k ++) {
				for (int d = 0; d <= 2; d ++) {
					int k2 = (2 * j - d) * (a[i + 1] - a[i]) + k;
					if (k2 > L || k2 < 0 || !dp[j][k][d]) continue;
					const int v = dp[j][k][d];
//					cout << i << ' ' << j << ' ' << k << ' ' << d << ' ' << v << '\n';
					if (j >= 2) 
						add(f[j - 1][k2][d], v * (j - 1) % mod);
					if (j >= 1) 
						add(f[j][k2][d], v * (2 * j - d) % mod);
					add(f[j + 1][k2][d], v * (j + 1 - d) % mod);
					if (d < 2 && j >= 1) 
						add(f[j][k2][d + 1], v * (2 - d) % mod);
					if (d < 2) 
						add(f[j + 1][k2][d + 1], v * (2 - d) % mod);
				}
			}
		}
		memcpy(dp, f, sizeof(f)), memset(f, 0, sizeof(f));
	}
	int ans = 0;
	for (int i = 0; i <= L; i ++) add(ans, dp[1][i][2]);
	cout << ans;
	return 0;
}
```
