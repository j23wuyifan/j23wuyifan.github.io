## 题意
给定一棵 $n$ 个点的树，可以选择若干条端点不同的简单路径作为公交线路。

乘坐一条线路，可以在这条路径上的任意两点之间移动。要求任意两点之间都能通过至多两条线路（即最多换乘一次）到达。

求满足条件的线路集合数量，对 $998244353$ 取模。$n\le 3000$。
## 思路
记 $u$ 能到的点的集合是 $S_u$，题目条件等价于对于任意的 $S_u,S_v$，都有 $S_u \cap S_v \ne \varnothing$。由于 $S_u$ 是一个树上连通块，所以又等价于 $\cap S_u \ne \varnothing$。

对于连通块有经典的点减边容斥。设 $A_u,B_e$ 分别表示所以点都能到 $u$ 和所有点都能经过 $e$ 的方案。答案就是 $\sum A_u - \sum B_e$。求出 $B_e$ 和 $A_u$ 难度差不多，所以考虑如何求出 $A_u$。直接做不好做，依旧考虑容斥。

任选非叶子为根，记：
- $s_u$：子树大小。
- $l_u$：子树内叶子的数量。
- $L$：整棵树的叶子数。

对非叶子 $u$，设 $f_{u,i}$ 表示：以 $u$ 为根，选出 $i$ 个叶子，钦定它们不能通过已选线路到达 $u$，其余叶子不限制的方案数。

初始 $f_{u,0}=1$，已经处理的点数 $t=1$。合并儿子 $v$ 时：
$$
f'_{u,i+j}\mathrel{+}=
f_{u,i}\binom{l_v}{j}
2^{\binom{s_v}{2}}
2^{(t-i)(s_v-j)}

$$
- $\binom{l_v}{j}$：选出 $v$ 子树内被钦定的叶子；
- $2^{\binom{s_v}{2}}$：$v$ 子树内部的线路不经过 $u$，可以任意选择；
- $2^{(t-i)(s_v-j)}$：跨越两部分的线路经过 $u$，两个端点都不能是被钦定的叶子。

这样做对每个点都是 $O(n^2)$，总复杂度 $O(n^3)$。

如果钦定子树外一定合法，只对原树的儿子做，总复杂度等于树背包的复杂度，是 $O(n^2)$。

固定子树内被容斥掉的 $i$ 个叶子，记
$$
a=s_u-i,\qquad b=n-s_u,\qquad c=L-l_u
$$

外部贡献为
$$
(2^a-1)^c\,2^{a(b-c)+\binom b2}
$$
对于父边 $(u, fa_u)$，内部方案数是
$$
\binom{l_u}{i}2^{\binom{s_u}{2}},
$$
外部贡献和点 $u$ 的是相同的。
## 代码

```cpp#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 3010, mod = 998244353;
int n, rt, s[N], l[N], pw2[N * N], C[N][N], h[N][N], f[N], g[N];
vector<int> E[N];
inline void dfs(int u, int fa) {
	l[u] = E[u].size() == 1, s[u] = 1;
	for (int v : E[u]) {
		if (v == fa) continue;
		dfs(v, u);
		s[u] += s[v], l[u] += l[v];
	}
}
signed main() {
	cin >> n;
	for (int i = 1, u, v; i < n; i ++) {
		cin >> u >> v;
		E[u].push_back(v), E[v].push_back(u);
	}
	pw2[0] = 1;
	for (int i = 1; i <= n * n; i ++) pw2[i] = pw2[i - 1] * 2 % mod;
	for (int i = 0; i <= n; i ++) {
		C[i][0] = C[i][i] = 1;
		h[i][0] = 1;
		for (int j = 1; j < i; j ++)
			C[i][j] = (C[i - 1][j] + C[i - 1][j - 1]) % mod;
		const int v = (pw2[i] - 1);
		for (int j = 1; j <= n; j ++)
			h[i][j] = h[i][j - 1] * v % mod;
	}
	if (n <= 2) {
		cout << 1;
		return 0;
	}
	for (int i = 1; i <= n; i ++) if (E[i].size() > 1) {
			rt = i;
			break;
		}
	dfs(rt, 0);
	int ans = 0;
	for (int u = 1; u <= n; u ++) if (E[u].size() > 1) {
			memset(f, 0, sizeof(f));
			f[0] = 1;
			int t = 1, k = 0;
			for (int v : E[u]) {
				if (s[v] > s[u]) continue;
				memset(g, 0, sizeof(int) * (k + l[v] + 3));
				const int w = pw2[C[s[v]][2]];
				for (int i = 0; i <= k; i ++)
					for (int j = 0; j <= l[v]; j ++) {
						g[i + j] = (g[i + j] + f[i] * C[l[v]][j] % mod * w % mod * pw2[(t - i) * (s[v] - j)]) % mod;
					}
				t += s[v], k += l[v];
				memcpy(f, g, sizeof(int) * (k + 3));
			}
			for (int i = 0; i <= k; i ++) {
				int a = l[rt] - l[u], b = n - s[u], c = s[u] - i;
				int x = f[i];
				if (u != rt) x = (x - C[l[u]][i] * pw2[C[s[u]][2]] % mod + mod);
				x = x * h[c][a] % mod * pw2[C[b][2] + c * (b - a)] % mod;
				if (i & 1) ans = (ans - x + mod) % mod;
				else ans = (ans + x) % mod;
			}
		}
	cout << ans;
	return 0;
}
```
