## 题意
给定 $n,k$ 和数组 $x_0,\dots,x_{k-1}$。

枚举所有**长度不限的正整数序列** $A$，要求：

- 元素之和为 $n$；
- $A_i$ 是 $x_{i\bmod k}$ 的二进制子集。

每个序列的贡献为**首尾相接后，所有相邻两数之和的乘积**：
$$
\prod_{i=0}^{|A|-1}(A_i+A_{(i+1)\bmod |A|}).
$$

求所有合法序列的贡献之和，模 $10^9+7$。

$n\le 5\times10^4,\ k\le10,\ \sum n\le10^5$。

## 思路
对于每个因子 $A_i+A_{i+1}$，用 $c_i$ 表示选哪一项：
- $c_i=0$：选 $A_i$；
- $c_i=1$：选 $A_{i+1}$。

那么 $A_i$ 被选了 $1+c_{i-1}-c_i$ 次。因此，上一状态为 $p$，当前状态为 $q$，$a$ 的贡献为
$$
a^{1+p-q}
$$
枚举首尾状态 $s=0,1$。设 $f_{r,t,p}$ 表示当前总和为 $t$，下一个位置模 $k$ 为 $r$，上一状态为 $p$ 的贡献和。

初始 $f_{0,0,s}=1$，转移：
$$
f_{(r+1)\bmod k,t+a,q} \gets f_{r,t,p}\,a^{1+p-q}
$$
$a>0$，且 $a$ 是 $x_r$ 的子掩码。

最终取 $\sum_r f_{r,n,s}$，$s=0,1$ 的答案相加。

转移只用到了 $a^0,a^1,a^2$，所以只需维护三个和：
$$
\sum w,\qquad \sum wa,\qquad \sum wa^2.
$$

枚举 $x_r$ 的每个二进制位 $b=2^j$，可以不选，也可以选。

选了以后，$a$ 变成 $a+b$，三个量变成
$$
(u_0,\ u_1,\ u_2)
\longrightarrow
(u_0,\ u_1+bu_0,\ u_2+2bu_1+b^2u_0)
$$
这就是把 $(a+b)^2$ 展开。

所有位处理完，就得到了加入一个合法数的贡献。

时空复杂度 $O(nk\log n)$。

## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 1e5 + 10, mod = 1e9 + 7;
int T, n, k, x[11], m;
int f[11][N][2];
int g[11][17][N][2][3];
inline void add(int &x, int y) {
	x = x + y >= mod ? x + y - mod : x + y;
}
inline int solve(int s) {
	memset(f, 0, sizeof(f));
	for (int i = 0; i <= k; i ++)
		for (int j = 0; j <= m; j ++)
			for (int p = 0; p <= n; p ++) 
				memset(g[i][j][p], 0, sizeof(g[i][j][p])); 
	f[1][0][s] = 1;
	for (int t = 1; t <= n; t ++) {
		for (int r = 1; r <= k; r ++) {
			for (int j = 1; j <= m; j ++) {
				int b = 1 << j - 1;
				for (int p = 0; p < 2; p ++) {
					for (int d = 0; d < 3; d ++)
						g[r][j][t][p][d] = g[r][j - 1][t][p][d];
					if (!(x[r] & b) || t < b) continue;
					int v0 = g[r][j - 1][t - b][p][0];
					int v1 = g[r][j - 1][t - b][p][1];
					int v2 = g[r][j - 1][t - b][p][2];
					add(v0, f[r][t - b][p]);
					add(g[r][j][t][p][0], v0);
					add(g[r][j][t][p][1], (v0 * b + v1) % mod);
					add(g[r][j][t][p][2], (v0 * b % mod * b + 
						v1 * b % mod * 2 + v2) % mod);
				}
			}
			int to = r == k ? 1 : r + 1;
			for (int p = 0; p < 2; p ++)
				for (int q = 0; q < 2; q ++)
					add(f[to][t][q], g[r][m][t][p][1 + p - q]);
		}
	}
	int ans = 0;
	for (int i = 1; i <= k; i ++) add(ans, f[i][n][s]);
	return ans;
}
signed main() {
	cin >> T;
	while (T --) {
		cin >> n >> k;
		for (int i = 1; i <= k; i ++) cin >> x[i];
		m = 0;
		while ((1 << m) <= n) m ++;
		int ans = solve(0);
		add(ans, solve(1));
		cout << ans << '\n';
	}
	return 0;
}
```
