## 题意
给定 $n$ 个带权点，枚举所有满足 **根为 $1$，且每个点的父亲编号小于自身编号** 的树。

对每棵树，每个非叶子节点只保留通向**编号最大的儿子**的边，将树拆成若干条链。

每条链的权值为
$$
\sum_{x\text{ 在链上}}(val_x+1),
$$
整棵树的价值为所有链的权值之积。

求所有合法树的价值之和，对 $998244353$ 取模。$n\le 500$。
## 思路
令 $w_i=val_i+1$。

先把链的贡献换一种算法：每条重链恰好选一个点，选点 $x$ 产生 $w_x$ 的贡献。对所有选法求和，正好就是各条链权值和的乘积。

所以问题变成：枚举合法树，并在每条重链上恰好选一个点，求权值之和。
从大到小处理点 $n,n-1,\dots,1$，处理一个点时，给它选择父亲。

由于大的儿子先出现：
- 父亲还没有儿子：当前点成为重儿子，链向上延伸。
- 父亲已经有儿子：当前点成为轻儿子，当前链结束，必须已经选过点。

有三种状态：
- 空：没有儿子
- 未选：重链还没有选点
- 已选：重链已经选点
设 $f_i[a][b]$ 为：剩下 $1\sim i$ 尚未处理，其中有 $a$ 个未选、$b$ 个已选的方案权值和。空点有 $i-a-b$ 个。

初始 $f_n[0][0]=1$。

转移有 $3$ 步。
- 取出 $i$：按比例
$$
\frac{i-a-b}{i},\quad \frac ai,\quad \frac bi
$$
分别转移到 $i$ 为空、未选、已选的情况，并将对应数量减一。

- 是否选 $i$：若当前链尚未选点，可以不选，或选 $i$ 并乘 $w_i$；否则只能不选。

- 选择父亲：设剩余空点有 $e=i-1-a-b$ 个，非空点有 $a+b$ 个。

    - 接到空点：乘 $e$，父亲继承当前链的未选／已选状态。
    - 接到非空点：必须当前链已选点，乘 $a+b$，父亲状态不变。

时间复杂度 $O(n^3)$。
 
## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 510, mod = 998244353;
int n, w[N], f[N][N], g0[N][N], g1[N][N], inv[N];
signed main() {
	cin >> n;
	inv[1] = 1;
	for (int i = 2; i <= n; i ++) inv[i] = inv[mod % i] * (mod - mod / i) % mod;
	for (int i = 1; i <= n; i ++) cin >> w[i], w[i] ++;
	f[0][0] = 1;
	for (int i = n; i >= 1; i --) {
		memset(g0, 0, sizeof(g0)), memset(g1, 0, sizeof(g1));
		for (int a = 0; a <= i; a ++)
			for (int b = 0; a + b <= i; b ++) {
				const int v = f[a][b];
				g0[a][b] = (g0[a][b] + (i - a - b) * inv[i] % mod * v) % mod;
				if (a) g0[a - 1][b] = (g0[a - 1][b] + a * inv[i] % mod * v) % mod;
				if (b) g1[a][b - 1] = (g1[a][b - 1] + b * inv[i] % mod * v) % mod;
			}
		for (int a = 0; a < i; a ++)
			for (int b = 0; a + b < i; b ++)
				g1[a][b] = (g1[a][b] + g0[a][b] * w[i]) % mod;
		if (i == 1) {
			cout << g1[0][0] << '\n';
			return 0;
		}
		memset(f, 0, sizeof(f));
		for (int a = 0; a <= i - 1; a ++)
			for (int b = 0; a + b <= i - 1; b ++) {
				const int e = i - 1 - a - b;
				f[a + 1][b] = (f[a + 1][b] + e * g0[a][b]) % mod;
				f[a][b + 1] = (f[a][b + 1] + e * g1[a][b]) % mod;
				f[a][b] = (f[a][b] + (a + b) * g1[a][b]) % mod;
			}
	}
	return 0;
}
```
