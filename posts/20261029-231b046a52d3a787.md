## 题意
给定一个长度为 $2n$ 的随机序列，其中 $1\sim n$ 各出现两次。

按顺序将每个数放入至多 **260 个栈**中的一个。之后，每次可以选择两个不同的栈，若栈顶相同，就同时弹出。

构造每个数所属的栈，使所有数最终都能被消除。只需输出分配方案，无需输出消除过程。

$n\le 5\times10^5$，保证序列在所有合法序列中等概率随机生成。
## 思路
记牌 $i$ 出现的两个位置是 $(l_i,r_i)$。按 $r_i$ 递增排序，每 $B$ 个分一块。

每块用一个独立栈，将所有 $l_i$ 放入。

块内按 $l_i$ 递增排序，将 $r_i$ 贪心划分成若干递增子序列，每条子序列对应一个公共栈。不同块复用公共栈。

正确性：考虑从最后一块开始做，块内每个公共栈的牌与独立栈中的相对顺序相同，所以一定能消除。

公共栈的数量是块内最长下降自序列的长度，随机排列下数量期望 $2\sqrt{B}$，独立栈共 $\frac{n}{B}$ 个。

$B=n^{\frac{2}{3}}$ 最优，期望要 
$$
\frac nB+2\sqrt B\approx3\sqrt[3]n
$$
个栈。时间复杂度 $O(n \log n)$。
## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 5e5 + 10;
int n, B, m, cnt, l[N], ans[N * 2], t[N];
pair<int, int> p[N];
signed main() {
	cin >> n;
	for (int i = 1, x; i <= n * 2; i ++) {
		cin >> x;
		if (!l[x]) l[x] = i;
		else p[++ cnt] = {l[x], i};
	}
	B = pow(n, 0.666);
	m = (n + B - 1) / B;
	for (int i = 1; i <= m; i ++) {
		int L = (i - 1) * B + 1, R = min(i * B, n);
		sort (p + L, p + R + 1);
		int tot = 0;
		for (int j = L; j <= R; j ++) {
			auto [x, y] = p[j];
			ans[x] = i;
			int k = lower_bound(t + 1, t + tot + 1, y, greater<int>()) - t;
			if (k > tot) tot ++;
			t[k] = y;
			ans[y] = k + m;
		}
	}
	for (int i = 1; i <= n + n; i ++) cout << ans[i] << ' ';
	return 0;
}
```
