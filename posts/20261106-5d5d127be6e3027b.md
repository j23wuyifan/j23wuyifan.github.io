## 题意
给定 $n$ 个数，进行 $k$ 次操作。

每次等概率随机选一个位置 $x$，将**其余所有数的乘积**加入答案，然后令 $a_x$ 减 $1$。

求最终答案的期望，对 $10^9+7$ 取模。
$$
n \le 5\times 10^3,k \le 10^9
$$
## 思路
观察一次操作乘积的变化：
$$
\prod_i a_i-(a_x-1)\prod_{i\ne x}a_i
=\prod_{i\ne x}a_i,
$$
这等于答案的增加量，所以求最后答案的期望等价于求 $\prod a_i$ 的期望。

当每个 $t_i$ 固定时，操作的种类数是 
$$
\frac{k!}{t_1!t_2!\cdots t_n!}
$$
考虑用指数生成函数。记 
$$
F_i(x)=\sum_{t \ge 0} \frac{(a_i-t)}{t!} x^t=(a_i-x)e^x
$$
答案就是 $[x^k]\frac{k!}{n^k}\prod F_i(x)$。
$$
\prod_{i=1}^n F_i(x)=e^{nx} \prod_{i=1}^n(a_i-x)
$$
设 $P(x) = \prod_{i=1}^n(a_i-x)=\sum_{i=0}^n p_i x^i$。

那么 
$$
[x^k]e^{nx}P(x)=\sum_{i=0}^n p_i \frac{n^{k-i}}{(k-i)!}
$$
前面还有一项 $k!$，则 $\frac{k!}{(k-i)!}$ 只有 $n$ 项，直接暴力求就是 $O(n^2)$ 的，可以通过。
## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int mod = 1e9 + 7, N = 5e3 + 10;
int n, k, a[N], p[N];
inline int qpow(int a, int b) {
	int ans = 1;
	while (b) {
		if (b & 1) ans = ans * a % mod;
		a = a * a % mod, b >>= 1; 
	}
	return ans;
}
signed main() {
	cin >> n >> k;
	int sum = 1;
	p[0] = 1;
	for (int i = 1; i <= n; i ++) {
		cin >> a[i];
		sum = sum * a[i] % mod;
		for (int j = n; j >= 0; j --) p[j] = (p[j] * a[i] - (j ? p[j - 1] : 0) + mod) % mod;
	}
	int ans = 0, w = 1;
	for (int j = 0; j <= min(n, k); j ++) {
		int v = p[j] * qpow(n, k - j) % mod * w % mod;
		ans = (ans + v) % mod;
		w = w * (k - j) % mod;
	}
	cout << (sum - ans * qpow(qpow(n, k), mod - 2) % mod + mod) % mod;
	return 0;
}
```
