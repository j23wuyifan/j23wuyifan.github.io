## 题意
给定一排 $n$ 个球。从中选出恰好 $m$ 个互不重叠的组，每组包含一个球或两个相邻的球，允许有球不被选。对每个 $m=1,2,\ldots,k$，求分组方案数，答案对 $998244353$ 取模。
$$
n \le 10^9,k<2^{15}
$$
## 思路
设计 DP 状态 $f_{i,j}$ 表示前 $i$ 个球选了 $j$ 个组，转移考虑第 $i$ 个球不选，单独一组还是和 $i-1$ 一组。有转移 $f_{i,j} \gets f_{i-1,j}+f_{i-1,j-1}+f_{i-2,j-1}$。

记 $F_i=\sum f_{i,j} x^j$，有 $F_i=(1+x)F_{i-1}+xF_{i-2}$。注意到这个可以矩阵快速幂优化，转移就做多项式乘法和加法，时间复杂度 $O(n \log n \log k)$。

## 代码

```cpp
int n, k;
struct Mat {
	poly_t a[2][2];
	inline void init() {
		a[0][0] = a[0][1] = a[1][0] = a[1][1] = {};
	}
	friend Mat operator * (const Mat &a, const Mat &b) {
		Mat c;
		c.init();
		for (int i = 0; i < 2; i ++)
			for (int j = 0; j < 2; j ++) {
				for (int k = 0; k < 2; k ++)
					c.a[i][j] += a.a[i][k] * b.a[k][j];
				c.a[i][j].resize(k + 2);
			}
		return c;
	}
};
signed main() {
	poly :: init();
	Mat trans, ans;
	trans.a[0][0] = {0};
	trans.a[0][1] = {{0, 1}};
	trans.a[1][0] = {1};
	trans.a[1][1] = {{1, 1}};
	ans.a[0][0] = {1};
	ans.a[0][1] = {{1, 1}};
	cin >> n >> k;
	n --;
	while (n) {
		if (n & 1) ans = ans * trans;
		trans = trans * trans, n >>= 1;
	}
	for (int i = 1; i <= k; i ++) cout << ans.a[0][1][i] << ' ';
	return 0;
}
```
