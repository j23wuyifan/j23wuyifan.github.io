## 题意
给定 $k,m$，对于每个 $n=1,\ldots,m$：

从 $1,\ldots,k$ 中选出 $n$ 个**互不相同的数并排列**，求所有这些序列的**元素乘积之和**，对 $998244353$ 取模。
$$
m \le 5 \times 10^5,k < 998244353
$$
## 思路
简单题。

先把序列变无序，最后乘上 $n!$ 即可。

从 $1 \sim k$ 中选 $n$ 个数的乘积之和，就是 
$$
[x^n]\prod_{i=1}^{k}(1+ix)
$$
$k$ 很大，考虑对多项式取 $\ln$，$\ln(1+t)=t-\frac{t^2}{2}+\frac{t^3}{3} \dots $。

所以 
$$
\begin{aligned}
\ln(\prod_{i=1}^{k}(1+ix))
&= \sum_{i=1}^k \sum_{j=1}^n\frac{(-1)^{j+1}}{j}(xi)^j \\
&= \sum_{j=1}^n \frac{(-1)^{j+1}}{j} x^j \sum_{i=1}^k i^j
\end{aligned}
$$
接下来只要对 $i \in [1,n]$ 求出 $\sum_{i=1}^k i^j$ 即可。

考虑 EGF，$\sum_{i=1}^k \frac{(ix)^j}{j!}=e^{ix}$。
$$
\sum_{j\ge0}\left(\sum_{i=1}^{k}i^j\right)\frac{x^j}{j!}
=\sum_{i=1}^{k}e^{ix}
=\frac{e^{(k+1)x}-e^x}{e^x-1}
$$
这个就把分子分母再转回展开形式，分母求逆后再乘上分子即可。

最后记得再做一遍 $\exp$。
## 代码

```cpp
int k, n, fac[N];
signed main() {
	poly :: init();
	cin >> k >> n;
	fac[0] = 1;
	for (int i = 1; i <= n + 1; i ++) fac[i] = fac[i - 1] * i % mod;
	poly_t p, q;
	for (int i = 1; i <= n + 1; i ++) p.push_back((qpow(k + 1, i) - 1) * qpow(fac[i], mod - 2) % mod);
	for (int i = 1; i <= n + 1; i ++) q.push_back(qpow(fac[i], mod - 2));
	p = p * inver(q);
	p.resize(n + 1);
	p[0] = 0;
	for (int i = 1; i <= n; i ++) {
		int v = p[i];
		v = v * fac[i - 1] % mod;
		if (i + 1 & 1) v = (mod - v) % mod;
		p[i] = v;
	}
	p = exp(p);
	for (int i = 1; i <= n; i ++) cout << p[i] * fac[i] % mod << '\n';
	return 0;
}
```
