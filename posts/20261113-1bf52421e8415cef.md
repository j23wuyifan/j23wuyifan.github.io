## 题意
给定长度为 $n$ 的序列 $a$ 和一个 $n\times n$ 的 01 矩阵 $F$。每次询问区间 $[l,r]$，求其中有多少个**有序下标对** $(i,j)$ 满足 $F_{a_i,a_j}=1$。

允许 $i=j$。当 $i\ne j$ 时，$(i,j)$ 和 $(j,i)$ 分别判断，因为 $F$ 可能不对称。

$n\le 7\times10^4$，$q\le 2.5\times10^7$。矩阵按位压缩给出，只需实现 `solve`，按询问顺序返回答案。
## 思路
给希罗酱写篇题解。

这个题矩阵的取值只有 $0/1$，再结合数据范围，容易猜测是除 $w$ 之类的状物。下面默认 $w=64$。先假设 $a_i=i$，矩阵求和，扫描线。记扫描完第 $t$ 行后的列和：
$$
b_j=\sum_{i=0}^{t}F_{i,j}
$$
那么答案就是时刻 $r$ 和时刻 $l-1$ 的  $\sum_{i=l}^{r} b_{i}$相减。

现在需要维护：
- 加入一行：对每个 $j$，令 $b_j\gets b_j+F_{t,j}$。
- 查询 $b_l+\cdots+b_r$。

直接做是 $O(n^2)$ 的，考虑优化。

把 $b$ 按 $w$ 分块。整块的和是容易维护的，接下来只讨论散块的和。

考虑一块内的 $64$ 个数 $x_0,\ldots,x_{63}$。对他们压位存储：
$$
c_{k,j}=x_{j,k}
$$

其中 $c_{k,j}$ 表示 $c_k$ 的第 $j$ 位。
加入一行时，这一块对应的输入记为 $v$。需要对所有满足 $v_j=1$ 的 $x_j$ 加一。
二进制加法中：
- 异或得到当前位；
- 按位与得到进位。

这就可以模拟出这 $64$ 次加法。

```cpp
for (int k = 0; v; k ++) {
	ull t = c[k] & v;
	c[k] ^= v;
	v = t;
}
```

这里 $k$ 有 $\log n$ 位，总时间复杂度是 $O(\frac{n^2\log n}{w} + q\log n)$ 的。

考虑对时间维按 $w$ 分块，每 $w$ 次就暴力更新答案，于是 $k$ 就只有 $\log w$ 位了，时间复杂度 $O(\frac{n^2\log w}{w} + q\log w)$。

剩下的就是 $a_i \ne i$ 的普通情况。我们要的矩阵是：

$$
G_{i,j}=F_{a_i,a_j}
$$

这个就是先对行做一遍替换，转置之后再对行做一遍替换。因为这里的求和行列是对称的，不用转置回去。

对行做替换，为了不开新的数组，将 $i$ 向 $a_i$ 连边，先做一遍类似于拓扑排序的东西，剩下若干个环，这个随便做下就好了。

转置将矩阵分成 $64\times64$ 的小块，每次枚举 $i,j$ 不同的二进制位转移，一个小块的时间复杂度 $O(w \log w)$，总的是 $O(\frac{n^2\log w}{w})$。这题就做完了。

## 代码
```cpp
inline void trans(ull *a) {
	for (int d = 32; d; d >>= 1) {
		ull msk = ~0ull / ((1ull << d) + 1);
		for (int i = 0; i < 64; i ++) if (!(i & d)) {
				ull t = ((a[i] >> d) ^ a[i + d]) & msk;
				a[i] ^= t << d;
				a[i + d] ^= t;
			}
	}
}
inline void trans(vector<ull> &f, int m) {
	ull x[64], y[64];
	for (int i = 0; i < m; i ++)
		for (int j = i; j < m; j ++) {
			for (int k = 0; k < 64; k ++) {
				x[k] = f[(i * 64 + k) * m + j];
				y[k] = f[(j * 64 + k) * m + i];
			}
			trans(x);
			if (i ^ j) trans(y);
			for (int k = 0; k < 64; k ++) {
				f[(j * 64 + k) * m + i] = x[k];
				if (i != j) f[(i * 64 + k) * m + j] = y[k];
			}
		}
}
inline void change(vector<ull> &f, const vector<int> &a, int m) {
	int n = a.size();
	vector<int> deg(n), que(n);
	for (int x : a) deg[x] ++;
	int h = 0, t = 0;
	for (int i = 0; i < n; i ++) if (!deg[i]) que[t ++] = i;
	while (h < t) {
		int x = que[h ++], y = a[x];
		memcpy(f.data() + x * m, f.data() + y * m, m * sizeof(ull));
		if (!--deg[y]) que[t ++] = y;
	}
	vector<ull> tmp(m);
	for (int i = 0; i < n; i ++) if (deg[i]) {
			memcpy(tmp.data(), f.data() + i * m, m * sizeof(ull));
			int x = i;
			while (a[x] != i) {
				int y = a[x];
				memcpy(f.data() + x * m, f.data() + y * m, m * sizeof(ull));
				deg[x] = 0;
				x = y;
			}
			memcpy(f.data() + x * m, tmp.data(), m * sizeof(ull));
			deg[x] = 0;
		}
}
struct node {
	ull c[6] = {};
	int s[65] = {};
	inline void add(ull x) {
		for (int k = 0; x; k ++) {
			ull y = c[k] & x;
			c[k] ^= x, x = y;
		}
	}
	inline void clear(ull x) {
		int sum = 0;
		for (int i = 0; i < 64; i ++) {
			sum += x >> i & 1;
			for (int j = 0; j < 6; j ++) sum += ((c[j] >> i) & 1) << j;
			s[i + 1] += sum;
		}
		memset(c, 0, sizeof(c));
	}
	inline int ask(int l, int r) {
		ull msk = (~0ull << l) & (~0ull >> (63 - r));
		int ans = s[r + 1] - s[l];
		for (int i = 0; i < 6; i ++)
			ans += __builtin_popcountll(c[i] & msk) << i;
		return ans;
	}
};
```
