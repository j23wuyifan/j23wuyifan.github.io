## 题意
给定平面上 $n$ 个点，任意三点不共线。点 $i$ 的标签为 $a_i$，所有标签构成 $1\sim n$ 的排列。

每次选两个点，交换它们的标签，并画出连接它们的线段。每条线段最多画一次，任意两条线段只能在公共端点处相交。

求任意一组操作，使每个点 $i$ 的标签变为 $i$。无解输出 $-1$，无需最小化操作次数。$n\le 2000$。
## 思路
任去一个点 $P$ 作为原点，其余点围绕 $P$ 极角排序。那么可以连的线段就是排序后相邻的两个点和以 $P$ 为端点的线段。

考虑如何构造一组解。由于 $a$ 是排列，一定存在若干个置换环。交换不在同一个置换环内的两个点，就可以将两个置换环合并。

只用相邻两个点的交换，一定可以做到只有一个置换环。考虑如何用与 $P$ 相连的边构造答案。每次交换 $P$ 和 $a_P$ 即可。

时间复杂度 $O(n \log n)$。 

## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 2010;
const double pi = acos(-1.0);
struct node {
	int x, y, v, id;
	double angle;
} a[N];
int n, fa[N], val[N];
inline bool cmp(node a, node b) {
	return a.x * b.y - a.y * b.x > 0;
}
inline int find(int x) {
	return fa[x] == x ? x : fa[x] = find(fa[x]);
}
inline void merge(int u, int v) {
	u = find(u), v = find(v);
	if (u != v) fa[u] = v;
}
vector<pair<int, int> > ans;
inline void add(int u, int v) {
	swap(val[u], val[v]);
	ans.emplace_back(u, v);
}
signed main() {
	cin >> n;
	for (int i = 1; i <= n; i ++) fa[i] = i;
	for (int i = 1; i <= n; i ++) {
		cin >> a[i].x >> a[i].y >> a[i].v, merge(i, a[i].v), a[i].id = i;
		val[i] = a[i].v;
	}
	int m = 0;
	for (int i = 1; i <= n; i ++)
		if (val[i] != i) a[++ m] = a[i];
	if (!m) {
		cout << 0 << '\n';
		return 0;
	}
	n = m;
	int p = 1;
	for (int i = 2; i <= n; i ++)
		if (a[i].x < a[p].x || (a[i].x == a[p].x && a[i].y < a[p].y))
			p = i;
	swap(a[1], a[p]);
	for (int i = 2; i <= n; i ++)
		a[i].x -= a[1].x, a[i].y -= a[1].y;
	sort(a + 2, a + n + 1, cmp);
	for (int i = 2; i < n; i ++) {
		int nxt = i == n ? 2 : i + 1;
		if (find(a[i].id) != find(a[nxt].id)) {
			merge(a[i].id, a[nxt].id);
			add(a[i].id, a[nxt].id);
		}
	}
	while (val[a[1].id] != a[1].id) {
		add(a[1].id, val[a[1].id]);
	}
	cout << ans.size() << '\n';
	for (auto [x, y] : ans) cout << x << ' ' << y << '\n';
	return 0;
}
```
