## 题意
给定一个数组 $a_1, a_2, \dots, a_n$，你需要将其分成 $k$ 个子段。

一个子段 $a_l, a_{l+1}, \dots, a_r$ 的权值定义为 $(r - l + 1) \cdot \max\limits_{l \le i \le r}(a_i)$。一个划分的权值是所有子段权值之和。

请你找到权值最小的划分方案。
$$
n \le 2 \times 10^4, k \le 100
$$
## 思路
由于 $k$ 比较小，直接做 $k$ 轮转移即可。考虑如何快速完成一轮转移。

有明显的 DP 转移：
$$
f'_i = \min_{i=0}^{j-1} f_j + (j-i) \cdot \max\limits_{j < k \le i}(a_k)
$$
这个是明显的斜率优化的形式，斜率为 $\max\limits_{j < k \le i}(a_k)$。

从前往后做，维护一个 $1 \sim i$ 的单调栈。对于单调栈上 $\max=w$ 的一段区间，只用找到 $\min(dp_j-jw)$ 即可（因为斜率都是 $w$）。

这个可以对每一段维护一个凸包，一次二分求出。求出这个后再对所有区间维护一个大凸包。

当单调栈要 pop 掉末尾元素时，先将两个小凸包启发式合并，再一次二分求出 $v=\min(dp_j-jw)$。然后将原来的值 pop 掉，再加入 $v$。时间复杂度 $O(nk \log n)$。

## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 2e4 + 10;
int n, k, a[N], f[N], g[N];
int pre[N], nxt[N], head[N], tail[N], s[N], h[N], old[N], bak[N], b[N];
inline bool chk(int x, int y, int z) {
    return (g[y] - g[x]) * (z - y) >= (g[z] - g[y]) * (y - x);
}
inline void merge(int x, int y, int &l, int &r) {
    while (1) {
        if (x < y && chk(pre[y], y, l)) y = pre[y];
        else if (l < r && chk(y, l, nxt[l])) l = nxt[l];
        else break;
    }
    nxt[y] = l, pre[l] = y, l = x;
}
inline int val(int u, int x) {
    return a[u] * x + b[u];
}
inline bool del(int x, int y, int z) {
    return (b[y] - b[x]) * (a[z] - a[y]) <= (b[z] - b[y]) * (a[y] - a[x]);
}
inline void solve() {
    int top = 0, len = 0;
    for (int i = 1; i <= n; i ++) {
        int l = i - 1, r = i - 1;
        while (top && a[s[top]] <= a[i]) {
            int u = s[top --];
            h[len] = bak[u], len = old[u];
            merge(head[u], tail[u], l, r);
        }
        while (l < r && g[l] - a[i] * l >= g[nxt[l]] - a[i] * nxt[l]) 
            l = nxt[l];
        head[i] = l, tail[i] = r;
        b[i] = g[l] - 1ll * a[i] * l;
        int L = len ? 2 : 1, R = len + 1;
        while (L < R) {
            int mid = L + R >> 1;
            if (del(h[mid - 1], h[mid], i)) R = mid;
            else L = mid + 1;
        }
        old[i] = len, bak[i] = h[L];
        h[len = L] = i, s[++ top] = i;
        L = 1, R = len;
        while (L < R) {
            int mid = L + R >> 1;
            if (val(h[mid], i) >= val(h[mid + 1], i)) L = mid + 1;
            else R = mid;
        }
        f[i] = val(h[L], i);
    }
}
signed main() {
    cin >> n >> k;
    for (int i = 1; i <= n; i ++) cin >> a[i];
    memset(g, 0x3f, sizeof(g));
    g[0] = 0;
    while (k --) {
        memset(f, 0x3f, sizeof(f));
        solve();
        memcpy(g, f, sizeof(f));
    }
    cout << f[n];
    return 0;
}
```
