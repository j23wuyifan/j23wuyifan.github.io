## 题意
给定 $n$ 个数轴区间。每选一对下标 $l\le r$，就得到一个价值：第 $l$ 到第 $r$ 个区间的**并集长度**，重叠部分只算一次。

求所有 $\frac{n(n+1)}2$ 个下标对中，**最大的 $k$ 个价值之和**。
$$
n \le 3 \times 10^5,a_i \le 10^9
$$
## 思路
将 $[l, r]$ 的线段转为 $[l,r)$ 的点。先考虑如何求出第 $k$ 大。

先二分答案，转为判定 $\ge mid$ 的有多少个区间。这个显然可以双指针。

新加一个 $r$ 就是将 $j \in [a_i,b_i)$ 的 $last_j\gets i$。$l\sim r$ 的并集长度就是又多少个 $last_j \ge l$。维护 $w_i=\sum [last_j=i]$。这样就可以 $O(1)$ 移动 $l$。

至于对 $[a_i,b_i)$ 的推平操作，用珂朵莉树维护即可。可以将珂朵莉树的操作预处理，时间复杂度 $O(n (\log n+\log V))$。

但是题目要求前 $k$ 大之和。

记第 $k$ 大为 $x$。我们容易求出 $>x$ 的有多少个区间，这样就知道 $x$ 取了多少个。对于 $>x$ 的区间的贡献就是对于每一个 $r$ 的 $\sum \min(last_j,l)$。这个就维护 $\sum_{last_j \le i} last_j$ 和 $\sum_{last_j \le i} 1$，就可以算出答案。至于这两个和也可以用 $w$ 数组 $O(1)$ 更新。

时间复杂度 $O(n(\log n + \log V))$。
## 代码

```cpp
#include<bits/stdc++.h>
#define IT set<node> :: iterator
#define int long long
using namespace std;
const int N = 3e5 + 10;
int n, k, a[N], b[N], mx;
int p[N], d[N], c[N], ans;
vector<pair<int, int> > e; 
struct node {
    int l, r;
    mutable int v;
    friend bool operator < (const node &a, const node &b) {
        return a.l < b.l;
    }
};
set<node> s;
inline IT split(int pos) {
    //l ~ pos - 1, pos ~ r
    if (pos > mx) return s.end();
    IT it = s.lower_bound({pos, 0, 0});
    if (it != s.end() && it -> l == pos) return it;
    it --;
    int l = it -> l, r = it -> r, v = it -> v;
    s.erase(it);
    s.insert({l, pos - 1, v});
    return s.insert({pos, r, v}).first;
}
inline void assign(int l, int r, int x) {
    IT itr = split(r + 1), itl = split(l);
    p[x] = e.size();
    d[x] = d[x - 1] + r - l + 1;
    for (auto it = itl; it != itr; it ++) {
        int v = it -> v;
        if (!v) continue;
        int len = it -> r - it -> l + 1;
        e.emplace_back(v, -len);
        d[x] -= len;
    }
    e.emplace_back(x, r - l + 1);
    s.erase(itl, itr);
    s.insert({l, r, x});
}
inline int calc(int t, bool f) {
    memset(c, 0, sizeof(c));
    if (f) ans = 0;
    int l = 0, len = 0, w = 0, cnt = 0;
    auto add = [&] (int x, int v) {
        c[x] += v;
        if (x <= l) {
            len += v;
            if (f) w += x * v;
        }
    };
    for (int r = 1; r <= n; r ++) {
        for (int i = p[r]; i < p[r + 1]; i ++)
            add(e[i].first, e[i].second);
        while (l < r && d[r] - len >= t) {
            l ++;
            len += c[l];
            if (f) w += c[l] * l;
        }
        cnt += l;
        if (f) ans += w + l * (d[r] - len);
        else if (cnt >= k) return cnt;
    }
    return cnt;
}
signed main() {
    ios :: sync_with_stdio(0);
    cin.tie(0), cout.tie(0);
    cin >> n >> k;
    for (int i = 1; i <= n; i ++) {
        cin >> a[i] >> b[i];
        mx = max(mx, b[i] - 1);
    }
    s.insert({1, mx, 0});
    e.reserve(3 * n);
    for (int i = 1; i <= n; i ++)
        assign(a[i], b[i] - 1, i);
    p[n + 1] = e.size();
    int l = 1, r = d[n];
    while (l < r) {
        int mid = l + r + 1 >> 1;
        if (calc(mid, 0) >= k) l = mid;
        else r = mid - 1;
    }
    int cnt = calc(l + 1, 1);
    cout << ans + (k - cnt) * l;
}
```
