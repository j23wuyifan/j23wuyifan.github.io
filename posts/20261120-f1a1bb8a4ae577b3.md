## 题意
给定一个长度为 $n$ 的括号串，反转一个位置有代价 $c_i$，求最小代价使得括号串不能在修改至多 $k$ 个位置的情况下变成合法括号串。
$n \le 10^5$
## 思路
简单题，场切了。

首先它给的括号串是没用的，如果是 $)$ 就把 $c_i$ 取反即可。相当于是把左括号换成右括号，代价是 $c_i$。

考虑一个括号串使得它变合法的最小操作次数，显然先把能匹配的都匹配掉，剩下前缀有 $R$ 个右括号，后面跟着 $L$ 个左括号。最小操作次数就是 
$$
\left\lceil\frac R2\right\rceil+\left\lceil\frac L2\right\rceil
$$

考虑枚举分界点 $i$，设前缀有 $p$ 个 $($，后缀有 $q$ 个 $)$，前面有 $i-2p$ 个 $($ 为匹配，后面有 $n-i-2q$ 个左括号未匹配。需要反转的最小次数是：
$$
\left\lceil\frac {i-2p}2\right\rceil+\left\lceil\frac {n-i-2q}2\right\rceil=\frac{n}{2}+i\bmod 2-p-q >k
$$
设 $c_i=p+q$，条件就是
$$
\max(\frac n2+i\bmod 2-c_i) > k \iff \min(c_i)<\frac n2+i\bmod 2-k
$$
考虑枚举 $i$ 使得 $c_i<\frac n2+i\bmod 2-k$。每次 $i \gets i+1$ 只会改变一个位置的贡献，查询考虑尽可能减去大的贡献，用树状数组维护前 $k$ 大的正收益即可。时间复杂度 $O(n \log n)$。
## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 2e5 + 10, inf = 1e18;
int n, k, m, a[N], b[N], v[N], id[N], cnt[N], sum[N];
int num, tot, now, ans = inf;
inline void add(int x, int d) {
	num += d;
	tot += v[x] * d;
	for (int p = x; p <= m; p += p & -p) {
		cnt[p] += d;
		sum[p] += v[x] * d;
	}
}
inline int qry(int t) {
	if (t >= num) return tot;
	if (!t) return 0;
	int nd = num - t, p = 0, s = 0;
	for (int i = __lg(m); i >= 0; i --) {
		int q = p + (1LL << i);
		if (q <= m && cnt[q] <= nd) {
			nd -= cnt[q];
			s += sum[q];
			p = q;
		}
	}
	return tot - s - nd * v[p + 1];
}
string s;
signed main() {
	ios :: sync_with_stdio(0);
	cin.tie(0), cout.tie(0);
	cin >> n >> k;
	cin >> s;
	for (int i = 1, x; i <= n; i ++) {
		cin >> x;
		if (s[i - 1] == '(') b[i] = x;
		else a[i] = x;
	}
	if (k * 2 >= n && n % 2 == 0) {
		cout << "?";
		return 0;
	}
	if (n & 1) {
		int res = 0;
		for (int i = 1; i <= n; i ++) res += min(a[i], b[i]);
		cout << res << '\n';
		return 0;
	}
	for (int i = 1; i <= n; i ++) v[i] = abs(a[i] - b[i]);
	sort(v + 1, v + n + 1);
	m = unique(v + 1, v + n + 1) - v - 1;
	for (int i = 1; i <= n; i ++) {
		id[i] = lower_bound(v + 1, v + m + 1, abs(a[i] - b[i])) - v;
		now += a[i];
		if (a[i] > b[i]) add(id[i], 1);
	}
	for (int i = 0; i <= n; i ++) {
		int t = n / 2 + (i & 1) - k - 1;
		if (t >= 0) ans = min(ans, now - qry(t));
		if (i == n) break;
		int j = i + 1;
		now += b[j] - a[j];
		if (a[j] > b[j]) add(id[j], -1);
		if (a[j] < b[j]) add(id[j], 1);
	}
	cout << (ans == inf ? -1 : ans) << '\n';
	return 0;
}
```
