## 题意
给出一个 $n$ 个点 $m$ 条边的无向图，第 $i$ 条边有两个权值 $a_i$ 和 $b_i$ 。
求该图的一棵生成树 $T$ ，使得
$$\left(\sum_{e\in T}a_e\right)\times\left(\sum_{e\in T}b_e\right)$$
最小。
$1 \le n \le 200,m \le 10000,0\le a_e,b_e \le 255$
## 思路
设 $x = \sum_{e \in T} a_e,y=\sum_{e\in T}b_e$。

答案一定可以在左下凸包的顶点中取得。因为左下凸包的斜率为负，$xy=k1_x-k_2 x^2$。最小一定在端点处取到。

考虑如何求出这个凸包。设 $L,R$ 分别是凸包的最左最右的端点，设 $\alpha=L_y-R_y,\beta = R_x - L_x$。对于 $LR$ 这条线段上的点 $(x,y)$，一定有 $\alpha x+\beta y=\alpha L_x+\beta L_y$。

尝试求出一个在直线下面的点，即 $\alpha x+\beta y < \alpha L_x+\beta R_x$。按 $w_e=\alpha a_e+\beta b_e$ 跑最小生成树即可。若最小生成树对应的点 $P$ 在 $LR$ 直线下，就递归处理 $L,P$ 和 $P,R$ 即可。时间复杂度为 $O(k m\log m)$。$k$ 是凸包上的点数。

有经典结论：对于一个 $n \times n$ 的平面，凸包上的点数是 $O(n^\frac 23)$。因为凸包的总长度是 $O(n)$ 的，长度为 $r$ 的整点向量至多 $O(r^2)$ 个，所以第 $k$ 个整点向量长度至少为 $\sqrt{k}$。

所以 $k$ 个点的凸包长度至少为 $\sum_{i=1}^k \sqrt{i}=O(n^\frac 32)$，这个稍微积分一下就能算出来。所以 $k=O(n^\frac 23)$。

总时间复杂度为 $O((nV)^\frac 23 m\log m)$。其中 $V = 256$。可以通过。
## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
#define pii pair<int, int>
#define x first
#define y second
using namespace std;
const int N = 1e4 + 10;
int n, m, fa[N];
struct node {
	int u, v, a, b, w;
} e[N];
inline bool cmp(node a, node b) {
	return a.w != b.w ? a.w < b.w : a.a + a.b < b.a + b.b;
}
inline int find(int x) {
	return x == fa[x] ? x : fa[x] = find(fa[x]);
}
inline pii get() {
	sort (e + 1, e + m + 1, cmp);
	for (int i = 0; i <= n; i ++) fa[i] = i;
	int x = 0, y = 0;
	for (int i = 1; i <= m; i ++) {
		int u = find(e[i].u), v = find(e[i].v);
		if (u != v) {
			fa[u] = v;
			x += e[i].a, y += e[i].b;
		}
	}
	return {x, y};
}
int ansx = 1e9, ansy = 1e9;
inline void chk(pii a) {
	if (ansx * ansy > a.x * a.y ||
	(ansx * ansy == a.x * a.y && ansx > a.x)) ansx = a.x, ansy = a.y;
}
inline void solve(pii L, pii R) {
	if (L.x == R.x && L.y == R.y) return;
	int p = L.y - R.y, q = R.x - L.x;
	for (int i = 1; i <= m; i ++)
		e[i].w = p * e[i].a + q * e[i].b;
	auto P = get();
	chk(P);
	if (P.x * p + P.y * q != L.x * p + L.y * q) {
		solve(L, P);
		solve(P, R);
	}
}
signed main() {
	cin >> n >> m;
	for (int i = 1; i <= m; i ++)
		cin >> e[i].u >> e[i].v >> e[i].a >> e[i].b, e[i].w = e[i].a;
	pii L = get();
	for (int i = 1; i <= m; i ++)
		e[i].w = e[i].b;
	pii R = get();
	chk(L), chk(R);
	solve(L, R);
	cout << ansx << ' ' << ansy;
	return 0;
} 
```
