## 题意

给定一个长为 $n$ 的序列 $a_1,\ldots,a_n$，其中对于任意的 $i$ 满足 $1 \leq a_i \leq n$。

定义一个二元组函数如下：
$$f((l,r))=(\min\{a_l,\ldots,a_r\},\max\{a_l,\ldots,a_r\})(l \leq r)$$

你需要回答 $q$ 次询问，每次给定 $(l_i,r_i)$，问其最少经过多少次 $f$ 的调用（即 $(l,r) \rightarrow f((l,r))$）使得 $(l_i,r_i)$ 变成 $(1,n)$，若无解请输出 `-1`。
$n, q \le 10^5$。
## 思路
这题也太牛了。

对于 $[l,r]$，可以拆成 $[l, l+1],[l+1,l+2] \dots [r - 1,r]$。

因为 $[j-1,j]$ 和 $[j,j+1]$ 都有一个端点是 $a_j$，所以区间两两有交。
$$
f([l,r])=\bigcup_{i=l}^{r-1}f([i,i+1])
$$
扩展到 $k$ 次：
$$
f^k([l,r])=\bigcup_{i=l}^{r-1}f^k([i,i+1])
$$
如果能够求出所有的 $f^{2^k}([i,i+1])$，就可以做一个区间 $rmq$ 求答案了。

设 $[l,r] = f^{2^k}([i,i+1])$。$f^{2^{k+1}}=\bigcup_{i=l}^{r-1}f^k([i,i+1])$。也是做一下 $rmq$ 就好了。

时间复杂度 $O(n\log^2 n)$。
## 代码

```cpp
#include<bits/stdc++.h>
#define pii pair<int, int>
using namespace std;
const int N = 1e5 + 10;
int n, m, a[N];
struct node {
	int mn[N][19], mx[N][19];
	inline void init() {
		for (int i = 1; (1 << i) <= n; i ++)
			for (int j = 1; j + (1 << i) - 1 <= n; j ++) {
				mn[j][i] = min(mn[j][i - 1], mn[j + (1 << i - 1)][i - 1]);
				mx[j][i] = max(mx[j][i - 1], mx[j + (1 << i - 1)][i - 1]);
			}
	}
	inline pii qry(int l, int r) {
		if (l > r) return {N, 0};
		int k = __lg(r - l + 1);
		return {min(mn[l][k], mn[r - (1 << k) + 1][k]), 
		max(mx[l][k], mx[r - (1 << k) + 1][k])};
	}
}t[19];
inline void solve(int l, int r) {
	if (l == 1 && r == n) {
		cout << "0\n";
		return;
	}
	if (t[18].qry(l, r - 1) != make_pair(1, n)) {
		cout << -1 << '\n';
		return;
	}
	int ans = 0;
	for (int k = 17; k >= 0; k --) {
		auto [x, y] = t[k].qry(l, r - 1);
		if (x != 1 || y != n) {
			l = x, r = y;
			ans += 1 << k;
		}
	}
	cout << ans + 1 << '\n';
}
signed main() {
	ios :: sync_with_stdio(0);
	cin.tie(0), cout.tie(0);
	cin >> n >> m;
	for (int i = 1; i <= n; i ++) cin >> a[i];
	for (int i = 1; i <= n; i ++) {
		t[0].mn[i][0] = min(a[i], a[i + 1]);
		t[0].mx[i][0] = max(a[i], a[i + 1]);
	}
	t[0].init();
	for (int i = 1; i <= 18; i ++) {
		for (int j = 1; j <= n; j ++) {
			int l = t[i - 1].mn[j][0], r = t[i - 1].mx[j][0];
			auto [x, y] = t[i - 1].qry(l, r - 1);
			t[i].mn[j][0] = x, t[i].mx[j][0] = y;
		}
		t[i].init();
	}
	while (m --) {
		int l, r;
		cin >> l >> r;
		solve(l, r);
	}
	return 0;
}
```
