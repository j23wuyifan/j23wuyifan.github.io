## 题意
有 $n$ 个排成一行的城市，$a_i$ 表示城市 $i$ 最晚要在第几步被征服。第 $1$ 步任选一个城市，此后每步向左或向右扩展一格。如果从某个城市出发，存在一种扩展顺序能让所有城市都按时被征服，就称它为**合法起点**。

给定 $n,p$，对每个 $k=0,1,\ldots,n$，求有多少个数组 $a\in[1,n]^n$ **恰好有 $k$ 个合法起点**，答案对 $p$ 取模。
$n \le 3000$
## 思路
设 $L_t$ 为覆盖所有 $a_i \le t$ 和 起点 $s$ 的最小区间长度。合法的条件等价于所有 $L_t \le t$。容易发现每一个 $t$ 对应的合法的 $s$ 一定是一个区间，一堆区间的交还是一个区间。所以合法的 $s$ 是一个区间。

考虑枚举这一个区间 $[l, r]$，设区间长度为 $d=r-l+1$，区间内的方案就是 
$$
H_d=\prod_{i=l}^r (n-\max(i-l,r-i))=\prod_{i=1}^d(n-\max(i-1,d-i))
$$ 

设 $f_{l,r}$ 表示区间外的方案数。有转移
$$
f_{l,r}=(n-d)f_{l-1,r}+(n-d)f_{l,r+1}-(n-d-1)^2f_{l-1,r+1}
$$
就是考虑新加了哪个数，是 $l-1$ 还是 $r+1$，要求 $a_{l-1}/a_{r+1} > d$，方案数是 $n-d$，但是先加 $l-1$ 再加 $r+1$ 和先加 $r+1$ 再加 $l-1$ 会算 $2$ 次，这个要求 $a_{l-1},a_{r+1}\ge d+2$。

记 
$$
S_d=H_d\sum_{r-l+1=d}f_{l,r}
$$
对于一个长度恰好为 $k$ 的区间对所有 $d \le k$ 的贡献次数是 $k-d+1$。这个差分一次是至少为 $k$ 的区间的贡献，再差分一次即可。

时间复杂度 $O(n^2)$。

稍微优化一下也能做到线性。
## 代码

```cpp
#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N = 3e3 + 10;
int n, mod, f[N][N], h[N], T, s[N];
signed main() {
	ios :: sync_with_stdio(0);
	cin.tie(0), cout.tie(0);
	cin >> T;
	while (T --) {
		cin >> n >> mod;
		for (int d = 1; d <= n; d ++) {
			h[d] = 1;
			for (int i = 1; i <= d; i ++)
				h[d] = h[d] * (n - max(i - 1, d - i)) % mod;
		}
		for (int i = 0; i <= n + 1; i ++)
			for (int j = 0; j <= n + 1; j ++)
				f[i][j] = 0;
		f[1][n] = 1;
		for (int d = n - 1; d >= 1; d --) {
			for (int l = 1; l + d - 1 <= n; l ++) {
				int r = l + d - 1;
				f[l][r] = ((f[l - 1][r] + f[l][r + 1]) * (n - d) - f[l - 1][r + 1] *
				           (n - d - 1) * (n - d - 1)) % mod;
			}
		}
		s[n + 1] = s[n + 2] = 0;
		for (int d = 1; d <= n; d ++) {
			s[d] = 0;
			for (int l = 1; l + d - 1 <= n; l ++)
				s[d] += f[l][l + d - 1];

			s[d] = s[d] % mod * h[d] % mod;
		}
		int fac = 1;
		for (int i = 1; i <= n; i ++) fac = fac * n % mod;
		for (int i = 1; i <= n; i ++) {
			int x = s[i] - s[i + 1] * 2 + s[i + 2];
			fac -= x;
		}
		cout << (fac % mod + mod) % mod << ' ';
		for (int i = 1; i <= n; i ++) {
			int x = s[i] - s[i + 1] * 2 + s[i + 2];
			cout << (x % mod + mod) % mod << ' ';
		}
		cout << '\n';
	}
	return 0;
}
```
